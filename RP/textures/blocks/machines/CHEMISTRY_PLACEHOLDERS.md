# Temporary chemistry textures

Generated with the built-in image generation tool; front faces resized to 16x16 with nearest-neighbor sampling. Side/top/bottom faces reuse the existing Electrolyzer casing. On/off front textures are intentionally identical placeholders; block light changes while running.

Prompt shared by all three: square flat orthographic Minecraft machine front face, full-bleed coarse pixel art suitable for 16x16, dark gunmetal frame, steel corner bolts, no text, no perspective.

- Reaction Chamber: amber liquid window, agitator shaft, copper pipe detail.
- Chemical Converter: teal pressure vessel, valve, gas conduits, material feed hatch.
- Chemical Processor: violet separation vessel, filter plates, product drawer, gas pipe.

Replace each machine's named off/on face PNGs when final artwork is ready. The UI I/O faces reference the same textures.
